# Code of Conduct

We follow the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

Please contact conduct@norviq.dev in order to report violations of the Code of Conduct.

conduct@norviq.dev reaches the project's one maintainer (see [MAINTAINERS.md](MAINTAINERS.md)).
Norviq is not a CNCF project, so the CNCF Code of Conduct Committee does not handle reports about it
today. If and when Norviq is accepted into the CNCF, reports can also go to the
[CNCF Code of Conduct Committee](mailto:conduct@cncf.io), as the CNCF Code of Conduct describes.
